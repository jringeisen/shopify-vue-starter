# Theme App Extension - Product Rating

This is an example theme app extension that demonstrates how to add custom blocks to Shopify themes.

## What's Included

- **Product Rating Block**: A customizable product rating display
- **Star Rating Snippet**: A reusable star rating component
- **Localization**: Translation support

## Development

1. Start the Shopify CLI dev server:
   ```bash
   npm run shopify:dev
   ```

2. The extension will be available to add to your development store's theme via the theme editor.

3. Navigate to: Online Store > Themes > Customize > Add section/block > Apps

## Customization

Merchants can customize:
- Show/hide rating stars
- Show/hide review count
